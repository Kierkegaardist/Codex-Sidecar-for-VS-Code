# Security

Codex Sidecar runs on your own machine and sends nothing anywhere. What it reads and writes outside its own folder is listed in the README under "What it puts on your computer".

If you find a way it can be made to run something it should not, read or delete files that are not its own, or leak what a run held, please report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Please do not open a public issue for it.

Only the latest version is looked after.
